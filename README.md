# YouTube Clone

A modern YouTube Clone built with React.js that recreates the core YouTube experience with a clean interface, responsive design, authentication, and personalized user features.

The application allows users to search and watch videos, manage their own library, switch between light and dark themes, and enjoy a smooth user experience with loading skeletons and protected routes.

## Overview

This project was developed to strengthen my frontend development skills by building a real-world application using React and modern web technologies.

The main focus of this project is creating reusable components, implementing authentication with Local Storage, managing application state through Context API, integrating external APIs, and building a responsive interface inspired by YouTube.

## Installation

Clone the repository

```bash
git clone https://github.com/ronakdhandhukiya/YouTube-Clone.git
```

Navigate to the project directory

```bash
cd youtube-clone-react
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
VITE_RAPID_API_KEY=YOUR_API_KEY
```

Run the development server

```bash
npm run dev
```
